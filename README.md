**Voidstorm Arena** — a neon arena survival shooter. You are the Pulse
Warden, the last ship holding the arena gate: survive 12 waves of the
Voidstorm, collect XP shards, pick 1 of 3 upgrades after every wave, and
down the Void Colossus on waves 5, 10 and 12. WASD to move, mouse to aim,
hold click to fire. All art is drawn in code and all sound is synthesised
with WebAudio — no assets, no libraries, no network.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```
